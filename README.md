# 🌸 Iris Flower Classifier

## Task 5 — Streamlit Interactive ML Web App

This project demonstrates an end-to-end supervised machine learning
application.

A Decision Tree Classifier is trained using the Iris dataset and
serialized using Joblib. The trained model is then deployed through
an interactive Streamlit web application.

Users can enter flower measurements using sliders and receive a
real-time prediction.
